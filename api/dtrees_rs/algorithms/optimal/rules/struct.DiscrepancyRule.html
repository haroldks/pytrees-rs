pub struct DiscrepancyRule { /* private fields */ }
Expand description

Limited discrepancy search (LDS-DL8.5).

Features are ranked by the heuristic at each node, and taking the feature of rank i costs a discrepancy of i. A pass explores only the paths whose total discrepancy is within the budget; relaxing the rule raises the budget, following its StepStrategy, until it covers the whole space.

Kiossou, Schaus, Nijssen and Houndji, Time Constrained DL8.5 Using Limited Discrepancy Search (ECML PKDD 2022).
